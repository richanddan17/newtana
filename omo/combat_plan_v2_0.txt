태그

  [측정]      시트/GIF/에셋에서 직접 잰 값
  [구현]      현재 코드(spec v6)의 값이고 확정과 충돌하지 않는 것
  [구현수정]  확정 규칙에 맞추려면 코드를 바꿔야 하는 곳
  [제안]      작성자가 정한 기본값 (바꿔도 됨)
  [조정값]    Inspector에 노출해서 플레이하며 맞출 값
  [미정]      나중에 정하기로 한 것
  [추가예정]  사용자가 에셋을 따로 넣을 슬롯
용어
  windup  = 공격 전 준비 동작 구간 (검 강공격 0~3 / 마법 0~2 / 활 0~4)
  loop    = 홀드 동안 반복 재생되는 구간 또는 VFX
  자식    = 캐릭터(또는 소켓)를 따라가는 VFX
  월드    = 생성된 자리에 남는 VFX
  Foot    = 좌표 원점 (다리 중앙 x, 바닥선 y)

[1. 공통 규약]
==================================================================
1-1. 좌표계 [확정]
  - 원점 Foot = 다리 중앙 x, 바닥선 y. 오른쪽 +x, 위쪽 +y (y-up, Unity와 같음).
  - 단위는 도트(게임 픽셀). 좌표는 전부 Foot 기준 도트로 적는다.
  - 좌우 반전: 루트 scale.x = -1. 소켓과 VFX 오프셋의 x 부호가 함께 뒤집힌다.
    VFX 회전(up/down attack)은 반드시 자식의 로컬 회전으로 준다. 월드 회전으로 주면 왼쪽을 볼 때 방향이 반대가 된다.

1-2. 단위와 PPU [구현]
  - 1도트 = 0.01 유닛.
  - 몸 시트(4배, 12px/도트): PPU 1200
  - VFX 시트 vfx_rainbow_pack, vfx_projectiles(1배, 3px/도트): PPU 300
  - 슬래시 낱장 vfx_outlined_frames_all(12px/도트): PPU 1200
  - 강공격 시트 23_heavy_attack.PNG(2400x2736)는 이미 원본 해상도(12px/도트)다 [측정]. 다른 몸 시트와 같은 PPU 1200으로 임포트한다.
    (이전 v1.8의 5px/도트, PPU 495는 축소된 미리보기를 잘못 잰 값이라 폐기.)
  - 슬래시 heavy_0~5는 기존 낱장 PNG(12px/도트)를 쓴다.
  - 환산: 도트 = px / 12 (4배 시트), y-down 값은 y 부호만 뒤집는다.

1-3. 시간
  - 기본 20fps (프레임당 0.05s).
  - 예외 [구현]: 강공격 body 0.06s / muzzle 계열 0.03s / 탄·화살 0.04s / 먼지·링 0.04s / impact 0.04s
  - 프레임마다 지속시간이 다르면 표에 따로 적는다.

1-4. VFX 부착 규칙
  - 자식: 슬래시 낱장, gather, chargeLoop, bigLoop, muzzle 3종, arrow_release, aura, power_burst
  - 월드: impact 3종, arrow_impact, release, big_release, 먼지 3종, air_jump_ring, 탄·화살
  - 자식 VFX는 모션이 끊기면(피격, 무기 전환, 캔슬, 사망) 즉시 삭제한다. 월드 VFX는 끝까지 재생한다.
  - spawn 순간의 소켓 위치를 쓰고, 자식이면 소켓 오브젝트를 따라가게 한다.
  - 이펙트 레이어는 캐릭터와 탄 위. 슬래시는 additive 권장 [제안: 어두운 맵 additive, 밝은 맵 Normal].
    outlined 낱장은 additive에서 외곽선이 사라질 수 있으므로 재생해서 확인한다.

2-1. 키 우선순위와 겹침 [확정]
  - W + 좌클릭은 문 앞이나 사다리 위에서도 up attack이 우선이다.
  - 웅크리기 중 S + 좌클릭: 웅크리기가 풀리고 down attack이 나간다.
  - 웅크리기 중 일반 좌클릭: 서서 하는 공격과 똑같이 재생한다.
    연타하면 공격이 계속 우선한다. 공격을 멈췄을 때 Shift를 아직 누르고 있으면 다시 웅크린다.
  - 스크롤은 한 틱에 한 단계만 넘어간다. 쿨다운 0.1~0.2s [조정값].
  - 입력은 액션 이름(Attack, Dash, Crouch, Jump, Grapple, WeaponNext, WeaponPrev, MagicMode, Up, Down)으로 받아 두면
    나중에 키를 바꾸기 쉽다 [제안].

2-2. 모드 표시 [확정]
  - 마법 Rapid/Charge 모드는 화면 왼쪽에 작은 UI로 표시한다. 전환 VFX는 없다.

[3. 상태와 입력 규칙 (공통)]
==================================================================
3-1. 탭 / 홀드 판정
  - 검: 0.22s [구현, 확정 - 마법과 다른 것은 의도]
  - 마법: 0.5s (gather 길이) [확정]
  - 활: windup 0~4 구간이 판정 역할 (7장)

3-2. 무기 전환 [확정]
  - 스크롤 또는 1/2/3.
  - 전환하는 순간 진행 중인 공격, 차지, 콤보를 모두 끊고 loop VFX(gather, chargeLoop, bigLoop, power_burst)를 끈다.
    홀드 중이어도 같다.
  - 그래플 중에도 전환할 수 있다.
  - 전환 모션 에셋은 없다. 즉시 전환 [제안]. 모션을 넣을지는 [미정].

3-3. 피격 / 사망
  - 피격(어느 상태든): 모든 공격과 차지 취소, loop VFX 끔, 히트박스 끔, 탄은 나가지 않음.
  - 피격 재생은 20_hurt 7프레임, 조작 복귀는 6프레임 시점(0.30s) [제안].
  - 피격 후 무적 [확정]. 무적 시간 [조정값].
  - 사망: 모든 이펙트 즉시 삭제, 입력 차단.
  - 대시 중 무적: [미정] (패링을 만들 때 결정).

3-4. 공격 중 이동 [확정]
  - 검의 모든 공격 중 이동 가능. 콤보 때 발이 안 움직여서 어색해도 그대로 둔다.
  - 검 강공격은 loop(4~20) 홀드 중에만 이동속도 디버프. 기본 50% [조정값].
  - 활, 마법 공격 중 이동 여부: [미정].

3-5. 조정값 [확정: Inspector 노출]
  - 히트스톱(기본 근접 타격 2프레임), 화면 흔들림(기본 콤보 3타 1회), 공격 중 이동 거리,
    강공격 이동 디버프, 피격 후 무적 시간, 스크롤 쿨다운, power_burst 링 높이 보정, 탄 속도·사거리.

3-6. 캔슬 [제안, 재생해 보고 조정]
  - 콤보: 마지막 판정 프레임 +1부터 다음 타 입력 접수.
  - 콤보 3타는 idx8부터 대시로 취소 가능. 강공격 베기는 idx4(몸 25)부터 대시 취소.
  - 마법 발사 확정 구간(cast 5~7)은 캔슬 불가, 8~10은 대시/점프로 캔슬 가능.
  - 착지 경직 = fall 12~14 (3프레임 0.12s) [확정], 공격 입력은 저장.
  - 구현에는 입력 버퍼가 없고 즉시 교체다 [구현]. 버퍼를 넣을지는 플레이 후 결정.

3-7. 패링 [미정, 후보 정리]
  - 피격 밀림 모션(21_hurt_knockback)은 패링 모션으로 쓰지 않는다 [제안]. 맞을 때와 같아 보여서 헷갈린다.
  - 모션 후보: 강공격 22번 프레임(검을 위로 비스듬히 치켜든 자세)을 패링 자세로 재사용 [제안, 1순위]. 차선: 웅크리기(08_crouch).
  - 성공 연출 후보: 패링 자세 유지 + 뒤로 1~2도트 밀림, 접촉점에 release 재생, 히트스톱 2~3프레임, 몸 흰색 번쩍(성공 때만).
  - 정해야 할 것: 입력 방식(짧은 순간에 누르는 타이밍형 vs 홀드형), 키, 판정 시간, 대시 무적과의 관계(13장 4번과 함께).

  - 웅크리기 중 S + 좌클릭은 웅크리기를 풀고 down attack (2-1).

11-1. 확정 규칙에 맞추기 위한 수정 [구현수정]
  1. 입력: X/Q/1·2·3 체계를 2장 키 표로 교체. 스크롤 무기 순환 + 쿨다운, E 마법 모드, 우클릭 그래플, Q 대시.
  2. 마법 차지: 0.20s 임계값 -> 0.5s(gather 길이). gather는 누른 순간 시작해서 0.5s 동안 다른 FX로 교체되지 않게.
  3. 마법 기본 모드 Charge -> Rapid.
  4. 마법 release / bigRelease FX 호출 삭제. 뗄 때는 loop와 aura만 끈다.
  5. aura 재생 조건을 6-6으로 변경 (Charge 전용 -> chargeLoop·bigLoop 중 + 마나 회복 중), 위치를 콜라이더 중앙으로.
  6. 5방향 조준 비활성. 활·마법은 바라보는 방향으로만.
  7. 활: 0~10 인트로 / 11~16 루프 / 발사 9·15 -> 7장 흐름(0~4 windup 역재생, 5~10 반복, 발사 9, 10에서 홀드 확인).

  8. 활 arrow_release를 매 발사마다 재생.
  9. 검 강공격: power_burst 연결 (몸 4 진입 시 1회, 뗌 즉시 종료, 자식).
  10. 검 피격 이펙트 release / big_release 신규 (슬래시 재생 중 피격 시, 적마다).
  11. 점프 공격 / up / down attack 신규 (attack1 슬래시 재사용, 회전).
  12. 웅크리기 중 공격, S+좌클릭 down attack, 공격 후 Shift 홀드면 다시 웅크림.
