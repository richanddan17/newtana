- 비교 기준: `omo/combat_plan_v1_9.txt` (563줄) → `omo/combat_plan_v2_0.txt` (590줄)

- 결론: v2.0은 전체 전투 개편이 아니라 **강공격 시트/에셋 정정 + heavy_gather 추가 + muzzle 변형 재생 방식 정정 + 패링 후보 추가**가 핵심이다. 키, 콤보, 활/마법 흐름, 대시, 기본 프레임은 그대로다.

## 1. 강공격 시트/PPU 정정 (가장 큰 변경)

- v1.9: `17_heavy_attack`, `IMG_1750`, 5px/도트, PPU 495, 11f → 폐기 대상.
- v2.0: `23_heavy_attack.PNG` (2400x2736), 원본 12px/도트, PPU 1200, 27f.
- 5열 x 6행, 셀 480x456px (40x38도트), 27개 낱장 PNG, 피벗 (0.475, 0), 아래끝 = 바닥선.
- Foot x = 19.0도트 (몸 중앙). 기존 18 / 20.58 혼용을 19.0으로 통일.
- `heavy_0~5`는 기존 낱장 PNG(12px/도트)를 그대로 사용.

## 2. 강공격 동작/이동

- v2.0 4-7: windup 0~3, loop 4~20, release 21~26.
- `heavy_gather` 신규: 8f x 0.05s, loop, 48x48도트(144px, PPU 300), 검 중앙 `(-9,+13)`도트, loop 진입 시 `power_burst`와 함께 재생, release 시 제거.

- 월드 이동: +6/+8/+6도트 (22~24f). 스프라이트 내부 이동을 빼고 외부 이동으로 적용하는 방향.
- `heavy_0`는 Dash/ 폴더가 아니라 강공격 전용. v2.0 10-3에서 “heavy_0~5는 강공격 낱장”으로 정리.
