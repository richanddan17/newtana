## 상세 스펙

### 1. 투사체 사격
- **탄속**: 20~30 유닛/초 (WeaponData에서 조절)
- **수명/사거리**: 15~20 유닛 (화면 너비 고려)
- **터널링 방지**: `Continuous` 충돌 + 이동 거리 Raycast (ProjectileData 구현됨)
- **풀링**: 필수 (초기 50개, 부족 시 확장)

### 2. 8방향 조준
```
입력 벡터 → 8방향 스냅 (45° 단위)
  ↑ (0,1)       ↗ (1,1)       → (1,0)       ↘ (1,-1)
  ↖ (-1,1)      ← (-1,0)      ↙ (-1,-1)     ↓ (0,-1)
```
- 키보드: WASD + 방향키 조합으로 8방향
- 게임패드: 오른쪽 스틱 아날로그 → 8방향 양자화
- 마우스: **미지원** (향후 옵션)

### 3. 대시
- **대시 거리**: 5~6 유닛
- **지속 시간**: 0.2~0.3초
- **쿨다운**: 1.0초
- **무적 프레임**: 대시 시작 0.15초간 (옵션, 기본 true)
- **사격 중 대시**: 가능 (대시 중 사격 오버레이 차단)
- **공중 대시**: 가능 (옵션)

### 4. 탄약 시스템 (확장 구조만)
```csharp
// WeaponData에 이미 정의됨
UseAmmo = false;      // 현재 끔
MagazineSize = 30;
ReloadTime = 1.5f;
StartingAmmo = 90;
```
- 켜면: UI 탄약 표시, 재장전 입력(Interact 키), 빈 탄창 시 자동 재장전 또는 수동만

### 5. 무적 시간
- **피격 무적**: 0.8초 (깜빡임 0.1초 간격)
- **부활 무적**: 1.5초
- **대시 무적**: 0.15초 (대시 시작 시)
- **합산 방식**: `InvincibilityTracker`로 여러 소스 관리 (health-damage 구현 시)

### 6. 애니메이션 (통짜 스프라이트 기준)
- **합본 클립 필요**: Idle, Run, Jump, Fall, Dash, Hurt, Death
- **사격 오버레이**: `Run+Shoot`, `Jump+Shoot`, `Idle+Shoot` 등 합본 클립
- **조준 방향별**: 정면/위/대각선/아래 → 각 상태×방향 클립 또는 블렌드 트리
- **Muzzle**: 방향별 위치 오프셋 데이터로 관리 (Animation Event 대신)
