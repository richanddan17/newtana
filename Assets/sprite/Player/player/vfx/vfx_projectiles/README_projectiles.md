# 탄환 VFX 6종 (한 사이클만 정리본)

원본 시트는 GIF 를 ezgif 로 뽑은 것이라, 탄이 화면을 가로질러 이동한 40프레임(칸 700px 폭)이 들어 있었습니다.
이 중 **모양이 반복되는 구간 한 사이클만** 골라서, 탄을 제자리에 고정(정렬)하고 가로 1줄로 다시 만들었습니다.
(다른 VFX 와 같은 형식: 20fps, 프레임당 50ms, 4배 확대 시트를 1배로 되돌린 도트 원본, Nearest 필터)

| 파일 | 종류 | 프레임 | 길이 | 용도 | 피벗(1x px) |
|---|---|---|---|---|---|
| 09_basic_bolt   | loop    | 4 | 200ms | 기본 탄    | 몸통 중심 |
| 12_rapid_bolt   | loop    | 4 | 200ms | 연사 탄    | 몸통 중심 |
| 15_big_orb      | loop    | 6 | 300ms | 큰 구체    | 구체 중심 |
| 18_energy_arrow | loop    | 3 | 150ms | 차지 화살  | 몸통 중심 |
| 17_arrow_release| oneshot | 3 | 150ms | 화살 발사  | 번쩍 중심 (오른쪽이 발사 방향) |
| 19_arrow_impact | oneshot | 4 | 200ms | 화살 적중  | 중심 |
정확한 크기/피벗은 `projectiles_manifest.json` 참고.

## 사용법
- **loop 탄**: 탄 오브젝트를 만들고 이 프레임을 계속 반복 재생. 이동은 코드로 (오른쪽이 진행 방향, 왼쪽으로 쏠 땐 flipX).
  원본 GIF 에서 탄이 움직인 속도 참고값: basic/rapid/energy_arrow 약 9px/프레임, big_orb 약 10.5px/프레임 (1x 도트 기준, 20fps)
- **arrow_release**: 활 앞(발사 위치)에 spawn → 3프레임 재생 후 삭제.
- **arrow_impact**: 맞은 위치에 spawn → 4프레임 재생 후 삭제. (별 → 링 → 불꽃 → 흩어지는 점/호 순서)
- 색은 원본 그대로(탄마다 팔레트가 다름). 다른 색이 필요하면 셰이더 Hue Shift.

## 어떻게 골랐나 (원본 시트 기준, 0부터)
- basic_bolt 16~19 / rapid_bolt 16~19 / energy_arrow 15~17 / big_orb 18~23 이 완전한 한 사이클 (같은 모양이 그 뒤로 반복됨을 픽셀 비교로 확인)
- arrow_release 는 0~3 번 칸이 [번쩍 -> 링 -> 불꽃 -> 빈 프레임] 순서의 한 사이클. 마지막 빈 프레임은 빼고 3프레임만 사용
- arrow_impact 는 5칸 주기 [점/호, 빈칸, 별, 박스, 링]. 실제 재생 순서는 별 -> 박스 -> 링 -> 점/호 이므로 7~10 번 칸 사용
