# Rapid 카메라 흔들림

- 적용: rapid 연사 구간만 (basic, big은 흔들림 없음)
- 대상: 카메라/배경 전체 (스프라이트 시트, UI는 그대로)
- 진폭: 가로 1dot, 세로 1dot (12px/dot 기준 12px, 최대 약 17px)
- 패턴: A(-1, 0) -> 원위치(0, 0) -> B(-1, +1) -> 원위치(0, 0) 를 계속 반복
  - x는 오른쪽이 +, y는 아래쪽이 +, 값은 화면이 원위치에서 밀린 양
  - 한 단계 = 데모 GIF 1프레임 (40~60ms)
- 시작: 첫 rapid muzzle 프레임 / 끝: 마지막 A 단계 다음에 (0, 0)으로 복귀
- 전체 흔들림 시간: 1200 ms
- 프레임별 값은 rapid_camera_shake.json 참고
