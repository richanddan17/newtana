# 02. INPUT SYSTEM REWORK

> 우선순위: **2**  
> 상태: **진행중**  
> 근거: `combat_plan_v1_8.txt` 2장(조작키), 11-1 항목 1번

## 목표
키바인딩을 계획서에 맞게 개편한다.

## 확정 키맵
| 기능 | 키 | 비고 |
|---|---|---|
| 좌우 이동 | A / D | 기존 유지 |
| 점프 | 스페이스바 | 기존 유지 |
| 대시 | Q | **신규** - 바라보는 방향으로 발동 |
| 웅크리기 | Shift (홀드) | 기존 유지 |
| 공격 | 마우스 좌클릭 | 탭/홀드 |
| Up Attack | W + 좌클릭 | 검 전용 (지상/공중) |
| Down Attack | S + 좌클릭 | 검 전용 (지상/공중) |
| 그래플 | 마우스 우클릭 | [미정] 조건은 나중에 |
| 무기 전환(순환) | 마우스 스크롤 | 위=검->활->마법->검, 아래=반대. 틱당 1단계, 쿨다운 0.1~0.2s |
| 무기 직접 선택 | 1 검 / 2 활 / 3 마법 | 기존 유지 |
| 마법 모드 전환 | E | Rapid <-> Charge. 마법 전용. 시전 중 불가 |
| 사다리/벽 위아래 | W / S 단독 | 사다리/벽에 붙어있을 때만 |
| 문 진입 | W | 문 앞에서 |

## 우선순위 규칙
- `W + 좌클릭`은 문 앞이나 사다리 위에서도 **Up Attack 우선**
- 웅크리기 중 `S + 좌클릭`: 웅크리기 풀고 **Down Attack**
- 웅크리기 중 일반 좌클릭: 서서 공격과 동일. 연타시 계속 공격 우선. 공격 멈추고 Shift 누르고 있으면 다시 웅크리기
- 스크롤 쿨다운 적용
