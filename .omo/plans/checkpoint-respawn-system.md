# Checkpoint Respawn System Plan (v2 - Run & Gun)

Unity 2D 횡스크롤 총게임의 체크포인트와 사망/부활 시스템을 구현해줘.

먼저 현재 프로젝트의 Player 구조, 체력/사망 처리, Room/카메라 구조를 확인한 뒤 구현한다. 기존 구조와 충돌하지 않도록 필요한 부분만 수정한다.

==================================================
[1. Checkpoint]
==================================================

플레이어가 체크포인트에 접촉하거나 지정된 조건을 만족하면 해당 체크포인트를 활성화한다.

- 현재 활성 체크포인트를 하나만 유지한다.
- 체크포인트 위치를 코드에 하드코딩하지 않는다. (씬의 체크포인트 오브젝트 Transform 사용)
- 체크포인트는 자신이 속한 Room을 알고 있다.
- 활성화 시 피드백(이펙트, 사운드)을 연결할 수 있게 한다.

==================================================
[2. 사망]
==================================================

플레이어가 사망하면 일반 Gameplay 상태에서 Death 상태로 전환한다. (health-damage-system의 사망 이벤트 사용)

- 사망 애니메이션과 실제 부활 시점을 분리한다.
- 사망 중에는 일반적인 이동/사격 입력을 처리하지 않는다.
- 낙사, 즉사 함정, 화면 아래 영역 이탈도 같은 사망 흐름으로 처리한다.
- 사망 시 이미 발사된 총알과 적 AI의 처리 규칙을 정한다. (기본값: 총알은 유지하되 플레이어에게 피해를 주지 않음)

==================================================
[3. Respawn]
==================================================

부활 시 마지막으로 활성화된 체크포인트 위치를 사용한다.

- 체크포인트가 없다면 프로젝트에서 지정한 기본 시작 위치를 사용한다.
- 월드 X/Y 좌표를 코드에 직접 입력하지 않는다.
- 부활 연출(페이드, 딜레이)을 넣을 수 있게 한다. 연출 길이는 Inspector에서 조절한다.
- 부활 위치가 막혀 있거나 적과 겹치는 경우의 안전 규칙을 정한다.

==================================================
[4. 상태 초기화]
==================================================

부활 시 다음 상태를 명확하게 초기화한다.

- HP와 무적 상태
- 이동 상태, 입력 버퍼
- 사격 상태 (연사 쿨다운, 재장전 진행, 조준)
- 탄약 (탄약 사용 시 정책에 따라 초기화 또는 유지)
- 피격 상태
- 대시 상태
- Rigidbody2D 속도
- 임시 버프/디버프

필요한 항목만 초기화하고 영구적인 진행 상태(획득한 무기, 업그레이드, 열린 문 등)는 유지한다.
영구 진행 상태에 무엇이 포함되는지 목록으로 정리하고, 세션 내 유지인지 디스크 저장인지 구분한다.

부활 직후 짧은 무적 시간을 준다. (health-damage-system의 무적 요청 방식 사용, 길이 Inspector 조절)

==================================================
[5. 적 리셋]
==================================================

적을 사망 시점 그대로 유지할지, 체크포인트 재시작 시 리셋할지는 별도의 정책으로 분리한다.

- 정책 예: 전부 리셋 / 현재 Room만 리셋 / 처치한 적은 유지
- 적 리셋이 필요한 경우 현재 Room 또는 Stage의 상태를 기준으로 처리한다.
- 적은 사망 시 Destroy하지 않고 비활성화/풀 반환하므로 리셋 시 다시 활성화할 수 있다. (enemy-ai-system.md 참고)
- 리셋 시 적의 체력, AI 상태, 위치, 탄약, 쿨다운을 초기화한다.
- 리셋 시 남아 있는 적 총알을 정리한다.

==================================================
[6. 체크포인트와 Room]
==================================================

현재 Room 정보와 체크포인트를 연결한다.

- 부활 후 현재 Room을 체크포인트의 Room으로 갱신한다.
- 부활 후 카메라가 이전 Room의 경계를 계속 사용하는 문제가 발생하지 않도록 Room System과 연결한다. (room-camera-system.md 참고)
- 부활 시 카메라는 부활 위치로 즉시 이동시킨다.

==================================================
[7. 구현 목표]
==================================================

1. 체크포인트 저장
2. 사망 (낙사/함정 포함)
3. Respawn과 연출
4. 플레이어 상태 초기화 (사격/탄약 포함)
5. 부활 후 무적
6. 적 리셋 정책 (비활성화 기반)
7. Room System 연동
8. 영구 진행 상태 구분
9. 하드코딩 최소화
