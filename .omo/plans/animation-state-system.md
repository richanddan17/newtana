# Animation State System Plan (v2 - 2D Run & Gun)

Unity 2D 횡스크롤 총게임의 플레이어 애니메이션 상태 시스템을 정리하고 구현해줘.

먼저 현재 Animator Controller, Animation Clip, Sprite 구조(스프라이트가 통짜인지 상체/하체 분리인지), 기존 스크립트를 확인한다.

이 문서는 플레이어 애니메이션을 다룬다. 적 애니메이션은 enemy-ai-system.md에서 같은 원칙으로 처리한다.

==================================================
[1. 상태 목록]
==================================================

기본 상태:

- Idle
- Run (Walk가 별도로 있으면 포함)
- Jump/Rising
- Fall
- Hurt
- Death

선택 상태 (프로젝트에 클립이 실제로 있을 때만):

- Dash
- Reload
- Crouch / Aim-Up 등 조준 전용 자세

사격(Shoot)은 독립된 상태가 아니라 이동 상태 위에 겹치는 "오버레이"로 취급한다. (3번 항목 참고)

삭제된 상태: Parry, Counter Attack, Combo Attack, 근접 Attack.

현재 프로젝트에 실제 존재하는 애니메이션만 사용하고 없는 상태는 새로 강제 생성하지 않는다.

==================================================
[2. 로직 상태와 Animator 분리]
==================================================

게임 로직이 현재 상태를 판단하고, Animator에는 필요한 파라미터만 전달한다.
Animator 상태 구조를 로직 상태 구조와 똑같이 강제하지 않는다.

예상 Animator 파라미터 (프로젝트 실제 구조에 맞게 조정):

- Speed (float, 수평 속도 절댓값)
- VelocityY (float)
- IsGrounded (bool)
- IsShooting (bool)
- AimDir (int 또는 float, 조준 방향 구분)
- IsDashing (bool, 대시가 있을 때)
- Hurt (trigger)
- IsDead (bool)

애니메이션 전환 스크립트와 이동/사격 로직은 서로 강하게 결합하지 않는다.
애니메이션 쪽은 "읽기만" 하고 이동/사격 로직을 직접 호출하지 않는다.

==================================================
[3. 우선순위와 사격 오버레이]
==================================================

이동 계열 상태의 우선순위:

Death
→ Hurt
→ Dash
→ Jump/Fall
→ Run
→ Idle

사격은 이 우선순위를 대체하지 않고 위에 겹친다.

- Idle + Shoot, Run + Shoot, Jump + Shoot, Fall + Shoot가 모두 가능해야 한다.
- Hurt, Death, Dash 중에는 사격 오버레이를 해제하거나 무시할지 규칙을 정한다. (기본값: Hurt/Death 중 해제, Dash 중 사격 불가)
- Hurt에서 돌아온 뒤 사격 입력이 계속 눌려 있으면 실제 입력 상태를 다시 판단해서 사격을 재개한다.

오버레이 구현 방식은 스프라이트 구조에 따라 선택한다.

- 상체/하체가 분리된 구조: Animator Layer로 상체 사격 레이어를 따로 둔다.
- 통짜 스프라이트 구조: "Run+Shoot", "Jump+Shoot" 같은 합본 클립을 사용하고, 파라미터(IsShooting)로 전환한다.

(참고: 2D 스프라이트 애니메이션에서는 3D의 Avatar Mask 방식이 통하지 않는다. 상하체 분리는 오브젝트를 나눈 구조에서만 가능하다.)

단, 현재 프로젝트의 실제 설계와 충돌하면 기존 설계를 기준으로 조정한다.

==================================================
[4. 조준 방향]
==================================================

조준 방향에 따른 애니메이션을 지원할 수 있게 한다.

- 기본 가정: 정면 / 위 / 대각선 위 / 아래(공중) 중 프로젝트에 존재하는 방향만 사용한다.
- 마우스 조준이나 8방향 조준을 쓴다면 방향 값을 구간으로 나누어 클립 또는 블렌드로 연결한다.
- 조준 방향 계산은 입력/사격 시스템이 하고, 애니메이션은 결과값(AimDir)만 받는다.
- 없는 조준 방향 클립을 억지로 만들지 않는다. 가장 가까운 존재하는 방향으로 대체한다.

==================================================
[5. 사격 애니메이션과 발사 타이밍]
==================================================

사격 애니메이션 길이와 실제 발사 시점, 발사 가능 여부를 같은 것으로 취급하지 않는다.

- 발사 가능 여부, 연사 속도, 탄약은 Weapon 시스템이 결정한다.
- 애니메이션은 "발사됨"이라는 결과를 보여주는 역할이다.
- 발사 시점을 애니메이션에 맞춰야 한다면 Animation Event를 사용하되, 이벤트가 누락되어도(애니메이션이 중간에 끊겨도) 사격 상태가 끝난 뒤 멈춘 상태로 남지 않도록 안전장치를 둔다.
- 연사 중 매 발마다 클립을 처음부터 다시 재생해서 애니메이션이 떨리지 않도록 한다. (루프 클립 또는 반복 재생 규칙 확인)

총구(Muzzle):

- 총알이 나가는 위치는 Muzzle Transform 기준으로 한다.
- 클립/조준 방향마다 총구 위치가 달라지면 Muzzle 위치를 방향별로 정의하거나 애니메이션으로 이동시킨다.
- 월드 좌표를 하드코딩하지 않는다.

==================================================
[6. 피격 / 사망 애니메이션]
==================================================

피격 애니메이션 재생 중 이동/사격 가능 여부를 Player State System과 연결한다.

- 피격 애니메이션이 끝났다고 무조건 Idle로 전환하지 말고 실제 게임 상태(지상/공중, 입력)를 다시 판단한다.
- 짧은 연속 피격에서 Hurt가 계속 재시작되어 애니메이션이 멈춘 것처럼 보이지 않도록 한다. (무적 시간과 연동)
- 피격 시 깜빡임(Flash/Blink)은 Animator가 아니라 별도 컴포넌트로 처리해도 된다.

사망:

- 사망 판정과 사망 애니메이션을 분리한다.
- Death 진입 후에는 다른 상태로의 자동 전환이 일어나지 않는다. (부활은 Checkpoint System이 처리)

==================================================
[7. 애니메이션 프레임]
==================================================

Sprite 애니메이션은 Unity의 Animation Clip과 Sprite Renderer 구조를 기준으로 관리한다.

- 매 프레임 Update에서 이미지를 직접 교체하는 방식은 사용하지 않는다.
- 필요한 경우 Animation Clip의 Sample Rate와 프레임 타이밍을 조정한다.

==================================================
[8. 방향 전환]
==================================================

방향 전환이 Collider, Muzzle, 이펙트 위치에 모두 반영되어야 한다.

- 권장: 시각 루트(또는 플레이어 루트)의 scale.x를 반전하거나 좌우 방향을 한 곳에서 관리한다. 이 경우 Muzzle과 Collider 오프셋이 함께 뒤집힌다.
- SpriteRenderer.flipX만 사용하면 Collider와 Muzzle은 뒤집히지 않는다. 이 방식을 쓴다면 Muzzle과 오프셋을 수동으로 미러링한다.
- 조준 방향(마우스/스틱)과 이동 방향이 다를 수 있다. 캐릭터가 바라보는 방향은 조준 방향 우선인지 이동 방향 우선인지 한 번에 정한다.
- 애니메이션별로 스케일을 임의로 변경하여 캐릭터 크기가 튀는 문제가 발생하지 않도록 한다.
