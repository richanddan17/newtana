# Enemy Animation Plan (Generic Run'n'Gun Pack 기준)

Unity 2D 횡스크롤 총게임의 적 애니메이션을 에셋 팩(`Enemies/`)에 맞춰 구현해줘.

먼저 현재 Enemy 프리팹, Animator 구조, 스프라이트 슬라이스 상태, enemy-ai-system.md의 상태 구조를 확인한다.
이 문서는 에셋에 실제 있는 프레임만 사용한다. AI 상태와 Animator를 1:1로 강제하지 않고, AI가 주는 값(상태, 조준 방향)을 Animator가 읽기만 한다.

==================================================
[1. 에셋 목록]
==================================================

| 파일 | 크기 | 프레임 | 종류 |
|---|---|---|---|
| ARMob.png | 768 x 38 | 24 (32 x 38) | 소총병. 이동하며 3방향 사격 |
| RPGmob.png | 440 x 44 | 10 (44 x 44) | 로켓병. 고정 사격 |
| SniperMob.png | 616 x 44 | 14 (44 x 44) | 저격수. 고정 정면 사격 |
| Explosion_Particle.png | 288 x 32 | 9 (32 x 32) | 폭발 이펙트 |

공통:

- 한 줄짜리 가로 시트다. Grid By Cell Size로 슬라이스한다.
- 모두 오른쪽을 보는 상태로 그려져 있고, 왼쪽은 루트 scale.x = -1 로 뒤집는다. (Collider와 Muzzle이 함께 뒤집힘)
- 프레임 번호는 왼쪽부터 0부터 센다.
- Import: Filter Mode Point, Compression None, 피벗은 발 기준으로 모든 프레임 통일.
- 전용 Hurt 클립은 어느 적에도 없다. 피격은 스프라이트 흰색 플래시로 처리한다.

[2. AR Mob (소총병)]
==================================================

| 클립 | 프레임 | 프레임 수 | 루프 |
|---|---|---|---|
| Idle | 0~2 | 3 | O |
| Shoot (정면) | 3~4 | 2 | O (총구 화염 교대) |
| Aim Up | 5 | 1 | - |
| Shoot Up | 6~7 | 2 | O |
| Aim Down | 8 | 1 | - |
| Shoot Down | 9~10 | 2 | O |
| Run | 11~18 | 8 | O |
| Death | 19~22 | 4 | X (마지막 프레임 유지) |
| 투사체(총알) | 23 | 1 | - |

- 조준 방향은 3가지다: 정면 / 위 / 아래. 대각선은 없다.
  AI가 계산한 조준 각도를 가장 가까운 3방향으로 스냅해서 AimDir로 전달한다.
- 이동(Run)과 사격은 별도 클립이다. 달리면서 쏘는 클립은 없으므로 사격 중에는 멈춰 서서 쏜다.
  (AI 상태: Chase/Reposition 중에는 사격 불가, Aim → Shoot 동안 정지)
- 후퇴(Retreat) 시 플레이어를 바라본 채 뒤로 가야 하면 Run 클립을 역재생(재생 속도 -1)한다.
  역재생을 쓰지 않으면 몸을 돌려 도망가는 방식으로 하고, 이때는 사격하지 않는다.
- 총알 스프라이트(23)는 작은 붉은 점이다. 투사체 프리팹의 스프라이트로 사용한다.

==================================================
[3. RPG Mob (로켓병)]
==================================================

| 클립 | 프레임 | 프레임 수 | 루프 |
|---|---|---|---|
| Idle / Aim | 0 | 1 | - |
| Fire | 1~4 | 4 | X (발사 → 후폭풍 → 복귀) |
| Death | 5~8 | 4 | X |
| 투사체(로켓 추정) | 9 | 1 | - |

- 앉아서 쏘는 고정형이다. 이동 클립이 없으므로 터렛형 AI(이동 없음, 조준/사격만)로 쓴다.
- 조준은 정면만 지원한다. 위/아래 조준 프레임이 없다.
- Fire 클립은 발사 순간(프레임 1~2에 화염과 로켓이 보임)이 있으므로 발사 시점을 Animation Event 또는 프레임 타이밍으로 연결할 수 있다.
  단, 실제 발사 가능 여부와 쿨다운은 Weapon 시스템이 결정한다. 이벤트가 누락되어도 상태가 멈추지 않게 안전장치를 둔다.
- 프레임 9가 로켓 투사체인지 확인한다. (프레임 2에 로켓이 화면 안에 이미 그려져 있어 연출용일 수 있음) 투사체 스프라이트는 필요하면 별도로 정한다.
- 로켓은 명중 시 폭발(Explosion_Particle)을 생성한다. 폭발은 범위 피해이므로 hitbox-hurtbox-system의 "범위 공격" 확장과 health-damage의 Hit Type(폭발)을 사용한다.

[4. Sniper Mob (저격수)]
==================================================

| 클립 | 프레임 | 프레임 수 | 루프 |
|---|---|---|---|
| Aim / Idle | 0 | 1 | - |
| Fire | 1~2 | 2 | X (총구 화염 후 소멸) |
| Bolt / Cooldown | 3~8 | 6 | X (노리쇠 동작과 탄피 배출 등) |
| Death | 9~12 | 4 | X |
| 투사체(총알, 빠른 탄) | 13 | 1 | - |

- 고정형이고 정면(수평) 사격만 가능하다. 위/아래 프레임이 없으므로 플레이어와 높이가 크게 다르면 쏘지 못하도록 AI에서 제한한다.
  (시야 판정에서 수직 허용 범위를 둔다.)
- 사격 후 Bolt 클립이 쿨다운 연출 역할을 하므로, Weapon 쿨다운 시간과 Bolt 클립 길이를 맞춘다. (둘 다 Inspector에서 조절)
- 프레임 3~8에 반짝임 등 작은 변화가 있다. 조준 예고(텔레그래프)로 쓸 수 있는지 눈으로 확인하고, 안 맞으면 별도 조준선 이펙트로 처리한다.
- 투사체 스프라이트(13)는 길쭉한 탄환 형태이므로 탄속이 빠른 무기 데이터와 맞춘다.

[5. 폭발 이펙트]
==================================================

Explosion_Particle.png, 9프레임, 32 x 32.

| 구간 | 프레임 | 내용 |
|---|---|---|
| 시작 | 0~1 | 어두운 원 → 흰색 섬광 |
| 폭발 본체 | 2~3 | 불꽃 |
| 소멸 | 4~8 | 불씨와 연기가 흩어지며 사라짐 |

- 이펙트는 한 번 재생하고 풀로 반환한다. (오브젝트 풀링)
- 피해 판정 시점은 이펙트 시작(프레임 0~2) 근처로 두고, 이펙트가 끝날 때까지 판정을 유지하지 않는다.
- 크기가 작으므로(32px) 로켓 폭발 범위에 맞게 스케일을 조절하되, 판정 크기와 시각 크기가 어긋나지 않게 한다.
- 일반 적 사망 이펙트로도 재사용할 수 있다.

[6. AI 상태 ↔ 애니메이션 연결]
==================================================

| AI 상태 (enemy-ai-system) | AR | RPG | Sniper |
|---|---|---|---|
| Idle / Patrol | Idle (Patrol 시 Run) | Idle | Idle |
| Detect | Idle (전용 클립 없음) | Idle | Idle |
| Chase / Reposition | Run | 없음 (이동 안 함) | 없음 |
| Aim | Aim Up / 정면 Idle / Aim Down | Idle | Aim |
| Shoot | Shoot / Shoot Up / Shoot Down | Fire | Fire |
| Cooldown | Idle | Idle | Bolt |
| Hurt | 흰색 플래시만 | 흰색 플래시만 | 흰색 플래시만 |
| Dead | Death | Death | Death |

- Detect 전용 클립이 없다. 필요하면 느낌표 아이콘이나 짧은 사운드로 표현한다.
- Hurt에서 경직(누적 임계값)이 필요하면 클립 없이 이동/사격을 잠깐 멈추는 것으로 처리한다.
- 사망 후에는 마지막 프레임을 잠시 유지한 뒤 비활성화(또는 풀 반환)한다. Destroy하지 않는다. (체크포인트 리셋을 위해)
- 리셋 시 Animator 상태를 Idle로 되돌리고 플래시/색상 등 임시 효과를 초기화한다.

==================================================
[7. 구현 목표]
==================================================

1. 3종 적 시트 슬라이스와 Import 설정
2. 프레임 매핑표대로 클립 생성
3. 적 종류별 Animator (AR: 이동 + 3방향 사격, RPG/Sniper: 고정 사격)
4. AI가 주는 AimDir/상태를 읽는 연동
5. 사격 시점과 Weapon 쿨다운 분리
6. 피격 흰색 플래시 (Hurt 클립 없음)
7. Death 후 비활성화와 리셋 시 초기화
8. 투사체 스프라이트(AR 23, RPG 9, Sniper 13)와 폭발 이펙트 풀링
9. 에셋에 없는 상태(Hurt, 위/아래 조준 등)를 억지로 만들지 않기
