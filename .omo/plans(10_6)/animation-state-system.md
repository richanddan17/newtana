# Player Animation Plan (v3 - Generic Run'n'Gun Pack 기준)

Unity 2D 횡스크롤 총게임의 플레이어 애니메이션을 에셋 팩(`Player/SpriteSheet_player.png`)에 맞춰 구현해줘.

먼저 현재 Animator Controller, Animation Clip, Sprite 슬라이스 상태, 기존 스크립트를 확인한다.
이 문서는 "에셋에 실제 있는 프레임"만 사용한다. 없는 프레임은 새로 만들지 않고 대체 규칙을 따른다.
상태 우선순위는 player-state-input-system.md, 방향 전환과 Muzzle 규칙은 이 문서의 [6]을 따른다.

==================================================
[1. 에셋 정보]
==================================================

- 파일: Player/SpriteSheet_player.png (360 x 315)
- 슬라이스: Grid By Cell Size 45 x 45, 8열 x 7행 (프레임 0~50 사용, 51~55는 빈 칸)
- 프레임 번호는 왼쪽 위부터 오른쪽으로, 행 순서대로 센다. (행0 = 0~7, 행1 = 8~15, ...)
- 캐릭터는 오른쪽을 보는 상태로 그려져 있다.
- 구조는 "통짜 스프라이트"다. 상체와 하체가 분리되어 있지 않으므로 Animator Layer로 상체만 겹칠 수 없다.
  이동 상태와 사격 상태를 합친 별도 클립을 쓴다.
- Import: Sprite Mode Multiple, Filter Mode Point, Compression None, Pivot은 발 기준(Bottom 또는 Custom)으로 모든 프레임이 같은 값이 되게 한다.
- (참고) SpriteSheet_player_sliced.png는 360 x 360이며 같은 45px 격자다. 둘 중 하나만 쓰고 섞지 않는다.

==================================================
[2. 프레임 매핑]
==================================================

| 클립 | 프레임 | 프레임 수 | 루프 | 비고 |
|---|---|---|---|---|
| Idle | 0~5 | 6 | O | 정지 |
| Run | 6~13 | 8 | O | 달리기 |
| Crouch | 14 | 1 | - | 앉기 정지 |
| Jump (상승) | 15 | 1 | - | 점프 상승 |
| Fall (하강) | 16 | 1 | - | 전용 프레임이 없어 16을 사용. 눈으로 확인 후 15/16 역할을 바꿀 수 있음 |
| Jump AimUp (무발사) | 17 | 1 | - | 공중에서 위를 보는 자세 |
| Idle Shoot (정면) | 18~19 | 2 | O | 총구 화염 2프레임 교대 |
| Idle Shoot Up | 20~21 | 2 | O | 위 조준 사격 |
| Crouch Shoot | 22~23 | 2 | O | 앉아 쏘기 (정면) |
| Run Shoot (정면) | 24~31 | 8 | O | 달리며 정면 사격 |
| Run Shoot Up | 32~39 | 8 | O | 달리며 위 사격 |
| Jump Shoot (정면) | 40~41 | 2 | O | 공중 정면 사격 |
| Jump Shoot Up | 42~43 | 2 | O | 공중 위 사격 |
| Jump Shoot Down | 44~45 | 2 | O | 공중 아래 사격 |
| Death | 46~50 | 5 | X | 공중에 뜬 뒤 쓰러짐. 마지막 프레임 유지 |

에셋에 없는 것:

- Hurt 전용 클립: 없음
- Dash, Reload, 착지(Landing), 앉아서 걷기, 대각선 조준: 없음
- 지상에서 사격하지 않는 "위 조준" 자세: 없음 (공중에는 17이 있음)
- 앉은 상태에서 위/아래 조준: 없음

==================================================
[3. 이 에셋으로 확정되는 규칙]
==================================================

- 조준 방향은 3가지다: 정면 / 위 / 아래(공중에서만). 대각선 조준은 지원하지 않는다.
  입력 시스템의 조준 스냅(Aim Snap)은 이 3방향(공중 아래 포함)으로 맞춘다.
- 지상에서 위 조준은 사격 중에만 보인다. 사격하지 않으면 정면 자세(Idle/Run)로 돌아간다.
  (사격 키를 뗀 뒤 짧은 유지 시간 후 복귀)
- 앉기(Crouch)는 에셋에 있으므로 상태로 지원한다. 앉은 상태에서는 정면 사격만 가능하고 이동은 불가다.
- 대시와 재장전은 에셋에 클립이 없으므로 기본 비활성이다. 넣으려면 클립을 새로 만들어야 한다.
- Hurt는 전용 클립이 없다. 기본 규칙은 "현재 자세 유지 + 피격 플래시(스프라이트 색 깜빡임)"이다.
  46~47(공중에 뜬 자세)을 짧은 넉백 피격 연출로 쓸지는 선택 옵션이며, 쓰면 끝난 뒤 자세가 어색한지 확인한다.
- 총구 화염은 스프라이트에 포함되어 있다. 별도 머즐 플래시 이펙트를 추가로 켜면 겹쳐 보이므로 둘 중 하나만 쓴다.

==================================================
[4. Animator 파라미터]
==================================================

- Speed (float, 수평 속도 절댓값)
- VelocityY (float)
- IsGrounded (bool)
- IsCrouching (bool)
- IsShooting (bool, 사격 유지 시간 포함)
- AimDir (int: 0 정면, 1 위, 2 아래)
- IsDead (bool)
- Hurt (trigger, 피격 플래시용. 클립 전환에는 쓰지 않아도 됨)

애니메이션 쪽은 값을 읽기만 하고 이동/사격 로직을 직접 호출하지 않는다.

==================================================
[5. Animator 구성]
==================================================

통짜 스프라이트이므로 상태를 조합 단위로 만든다.

지상:
- Idle / Idle_Shoot / Idle_ShootUp
- Run / Run_Shoot / Run_ShootUp
- Crouch / Crouch_Shoot

공중:
- Jump / Fall / Jump_AimUp(17)
- Jump_Shoot / Jump_ShootUp / Jump_ShootDown

공통:
- Death

전환 규칙:

- 우선순위는 Death → (Hurt 플래시, 상태 전환 없음) → 공중 → 앉기 → Run → Idle 이며 사격은 각 상태의 Shoot 변형으로 전환한다.
- 사격 시작/종료 전환은 Exit Time 없이 즉시 한다.
- 달리기 도중 Run ↔ Run_Shoot ↔ Run_ShootUp을 오갈 때 다리 동작이 처음으로 되돌아가 끊겨 보이지 않게 한다.
  세 클립은 모두 8프레임 같은 주기이므로 전환 시 정규화 시간을 이어받게 한다. (Transition Offset 또는 Motion Time 파라미터)
- 같은 이유로 Idle ↔ Idle_Shoot도 자연스럽게 이어지게 한다. (프레임 수가 달라 완벽할 필요는 없다.)
- Jump_Shoot 계열은 상승/하강 구분 없이 공중 사격 클립을 쓴다. (사격 프레임에 상승/하강 구분이 없음)
- Death 진입 후에는 다른 상태로 자동 전환하지 않는다. 부활은 Checkpoint System이 처리한다.

사격 표시 유지:

- 총구 화염 2프레임은 교대로 재생한다. 단발 사격에서 화염이 한 프레임만 번쩍하고 사라지지 않도록
  마지막 발사 후 짧은 시간(Inspector 조절, 기본 약 0.1~0.2초) 동안 IsShooting을 유지한다.
- 연사 속도와 애니메이션 속도는 별개다. 발사는 Weapon 시스템이 쿨다운으로 결정하고 애니메이션은 표시만 한다.

==================================================
[6. 방향 전환과 Muzzle]
==================================================

- 원본은 오른쪽을 본다. 왼쪽은 루트 scale.x = -1 로 뒤집는다. (Collider와 Muzzle이 함께 뒤집힘)
- SpriteRenderer.flipX는 Collider와 Muzzle을 뒤집지 않으므로 사용하지 않는다.
- 애니메이션별로 scale을 바꾸지 않는다.
- 바라보는 방향은 조준(입력) 방향 우선으로 한다. (뒤로 걸으며 사격 가능, 달리기 클립은 바라보는 방향 기준으로 재생)
- Muzzle Transform은 자세마다 위치가 다르므로 아래 자세별 위치를 따로 정의한다.
  * 정면 서기 / 앉기 / 달리기 / 공중 정면
  * 위 (서기 / 달리기 / 공중)
  * 공중 아래
- 위치는 각 사격 프레임의 총구 화염 중심 위치를 기준으로 찍고, 자세가 바뀔 때 Muzzle 위치를 갱신한다.
  (클립에서 Muzzle 오브젝트의 위치를 키프레임으로 두거나, AimDir/상태에 따라 코드에서 오프셋을 선택)
- 달리기 사격은 프레임마다 총 위치가 위아래로 약간 흔들린다. 발사 위치가 흔들려도 되는지, 고정할지 한 번 정한다.
  (권장: 자세별 고정 오프셋. 프레임 흔들림에 맞추지 않음)
- 월드 좌표를 하드코딩하지 않는다.

==================================================
[7. 재생 속도 (초기 제안값)]
==================================================

| 클립 | 프레임레이트 |
|---|---|
| Idle | 8~10 |
| Run / Run Shoot / Run Shoot Up | 12~14 |
| Idle/Crouch/Jump Shoot (화염 2프레임) | 12~16 |
| Death | 10~12 |

실제 값은 플레이하면서 조절한다. 클립별 Sample Rate를 Animation Clip에서 관리하고 코드로 재생 속도를 바꾸지 않는다.
이동 속도와 달리기 애니메이션 속도가 어긋나 발이 미끄러져 보이면 Run 클립 재생 속도 배율(Speed 파라미터 연동)을 둔다.

==================================================
[8. 피격 / 사망]
==================================================

- 피격: Hurt 상태에서도 현재 자세를 유지한다. 무적 시간 동안 깜빡임(알파 또는 흰색 플래시)을 별도 컴포넌트로 처리한다.
- 피격 후 상태는 실제 게임 상태(지상/공중, 입력)를 다시 판단해서 정한다.
- 사망: 사망 판정과 사망 애니메이션을 분리한다. Death 클립(46~50)을 재생하고 마지막 프레임을 유지한다.
- 공중에서 사망했을 때도 Death 클립을 재생한다. (바닥에 닿을 때까지 46~47을 유지하는 방식은 선택 사항)

==================================================
[9. 구현 목표]
==================================================

1. 45x45 슬라이스와 Import 설정, 발 기준 피벗 통일
2. 프레임 매핑표대로 클립 생성
3. 조합형 Animator 상태 (이동 + 사격)
4. 이동 중 사격 전환에서 다리 동작이 끊기지 않게 하기
5. 3방향 조준(정면/위/공중 아래)과 AimDir 연동
6. 앉기와 앉아 쏘기
7. 사격 표시 유지 시간
8. 루트 scale 기반 방향 전환과 자세별 Muzzle 위치
9. 피격 플래시와 Death 연동
10. 에셋에 없는 상태(Dash, Reload, 대각선, Hurt 클립)를 억지로 만들지 않기
