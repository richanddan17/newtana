# Sprite Asset Spec (v4 - Bot Wheel, Body/Arm 분리)

플레이어 스프라이트 에셋의 규격을 한곳에 정리한다. animation-state-system.md, weapon-projectile-system.md, hitbox-hurtbox-system.md가 이 문서의 값을 참조한다.

에셋 파일은 bot_wheel_sprites 폴더(body/, arm/, other/, manifest.json)에 있다.

==================================================
[1. 확정되지 않은 가정]
==================================================

아래 값은 기본 가정이다. 프로젝트와 다르면 이 문서만 고치고, 다른 문서는 이 문서를 참조한다.

| 항목 | 기본 가정 |
|---|---|
| Pixels Per Unit (PPU) | 16 (배경 타일 크기에 맞춰 바꿀 수 있음) |
| Unity 버전 | Unity 6 |
| 위/아래 4방향 팔 그림 | 회전 알고리즘으로 생성한 임시본 (최종 그림 아님) |
| Jump/Fall 몸통 | 달리기 프레임 재활용 임시본 |

PPU를 바꾸면 아래 표의 Unity 좌표(px / PPU)만 다시 계산한다.

==================================================
[2. 임포트 설정 (모든 PNG 공통)]
==================================================

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 16 (기본 가정값. [1] 참고. 바꾸면 [4], [5] 좌표를 다시 계산한다.)
- Filter Mode: Point (no filter)
- Compression: None
- 슬라이스: Sprite Editor의 Grid By Cell Size

셀 크기:

| 폴더 | 파일 | 셀 크기 |
|---|---|---|
| body/ | body_idle_aim(1), body_run_aim(8), body_jump_aim(1), body_fall_aim(1) | 64 x 32 |
| arm/ | arm_<방향>_shoot4(4), fx_<방향>_muzzle4(4) | 64 x 64 |
| other/ | idle_dormant, idle_carry, wake, run_carry, hurt, death, charge | 64 x 32 |
| other/ | dash_128wide | 128 x 32 |

방향 이름: front(0°), up45, up90, down45, down90

==================================================
[3. Pivot]
==================================================

Body 계열(64x32 셀)은 모두 같은 Custom Pivot을 쓴다.

- 64 x 32 셀: (0.289, 0.031)  (몸통 중앙 x=18.5px, 바퀴 아래 y=31px 기준)
- 128 x 32 셀(dash): (0.1445, 0.031)
- Arm(64 x 64): Center (0.5, 0.5). 이 점이 오른손 위치이고, 회전 중심이다.

==================================================
[4. Arm 앵커 (Body 셀 안의 팔 위치)]
==================================================

Arm 오브젝트의 localPosition. 계산식: ((ax - 18.5) / PPU, (31 - ay) / PPU), (ax, ay)는 Body 셀 안 픽셀 좌표(y 아래 방향)다.

| Body 프레임 | 앵커 px (ax, ay) | localPosition (PPU 16) |
|---|---|---|
| Idle | (21, 18) | (0.156, 0.8125) |
| Run 0, 4 | (21, 17) | (0.156, 0.875) |
| Run 1, 3, 5, 7 | (22, 19) | (0.219, 0.75) |
| Run 2, 6 | (22, 20) | (0.219, 0.6875) |
| Jump | (21, 17) | (0.156, 0.875) |
| Fall | (22, 20) | (0.219, 0.6875) |

==================================================
[5. Muzzle 위치 (Arm pivot 기준)]
==================================================

Muzzle의 localPosition = (x, -y) / PPU.  (px 값의 y는 아래 방향이므로 부호를 뒤집는다.)

| AimDir | 방향 | muzzlePx (x, y) |
|---|---|---|
| 0 | front | (8, -2) |
| 1 | up45 | (6.24, -7.07) |
| 2 | up90 | (2, -9) |
| 3 | down45 | (9.07, 4.24) |
| 4 | down90 | (6, 9) |

방향마다 위치가 다르므로 AimDir이 바뀔 때 함께 갱신한다. 값의 출처는 manifest.json이다.

==================================================
[6. 상태별 스프라이트 사용]
==================================================

| 상태 | Body 스프라이트 | Arm |
|---|---|---|
| Idle | body_idle_aim | 표시 |
| Run | body_run_aim | 표시 |
| Jump | body_jump_aim | 표시 |
| Fall | body_fall_aim | 표시 |
| Hurt | other/hurt | 숨김 |
| Death | other/death | 숨김 |
| Dash | other/dash_128wide | 숨김 |
| Wake (부활) | other/wake | 숨김 |
| 비활성 (시작 전) | other/idle_dormant | 숨김 |

확장용: other/idle_carry, other/run_carry (총을 내린 자세, 사용하지 않아도 됨), other/charge (차지샷용)

==================================================
[7. 충돌 판정과의 관계]
==================================================

- Hurtbox와 이동 Collider는 Body 기준이다. 크기는 몸통 약 11 x 22px (PPU 16에서 약 0.69 x 1.38 유닛)를 시작값으로 한다.
- Arm(총, 손)은 Hurtbox에 포함하지 않는다.
- 총구 이펙트(MuzzleFX)는 판정이 없는 연출이다.

==================================================
[8. 나중에 손볼 곳 (최종 그림 작업)]
==================================================

- 위/아래 4방향 팔: 특히 45° 두 방향은 도트로 직접 다듬기
- Jump, Fall 전용 몸통 그림
- 총을 내린 자세를 쓸 경우 해당 프레임 정리
- 최종 그림으로 바꿔도 셀 크기, pivot, 앵커 표를 유지하면 코드는 수정할 필요 없다.
