프레임별 모션 + VFX 동기화 가이드 v2 (검 / 활 / 마법 / 이동 / 피격)
==================================================================
v1 계획서 + 보유 모션 시트(motion_7.zip, 23종) + Rainbow VFX 팩(17종) + 레퍼런스 GIF 6개를 대조해서
"어떤 모션의 몇 번째 프레임에 어떤 VFX 의 몇 번째 프레임이 나오는지" 를 프레임 단위로 다시 정리했습니다.

표시 규칙
 [GIF확인] 레퍼런스 GIF 를 50ms(20fps) 단위로 풀어서 직접 확인한 값
 [시트확인] 보유 모션 시트 / VFX 매니페스트에서 직접 센 값
 [추정]     GIF 에 직접 안 보여서 비슷한 모션 기준으로 정한 값 (바꿔도 됨)
 [제안]     v1 에서 가져온 설계값 (GIF 로 반증되지 않은 것)
 [없음]     보유 에셋에 없음 -> 대체안 적어둠

0. v1 에서 바뀐 것 (먼저 읽기)
==================================================================
 1) 실제 모션 시트 프레임 수가 v1 가정과 달라서 전부 시트 기준으로 교체했습니다.
      콤보1  7 -> 8프레임   콤보2  7 -> 5프레임   콤보3 10 -> 10프레임 (동일)
      강공격 11 -> 11프레임(동일, 단 '모으기'가 시트 안에 포함: 아래 3번)
      마법   5 -> 11프레임(cast)   활  5 -> 22프레임(bow)
      피격   6 -> 7프레임(hurt) / 8프레임(hurt_knockback)
      점프 3 -> 13프레임, 이중점프 3 -> 14프레임, 대시 5프레임(동일)
 2) 모든 모션은 20fps(1프레임 50ms) 기준이고, GIF 를 보면 같은 포즈를 2틱(100ms) 유지하는 프레임이 많습니다.
    (아이들, 후딜, 강공격 앞부분, 연사 회복 등). 표의 "유지" 칸에 적었습니다.
 3) 연사(rapid) 2프레임 간격은 GIF 로 확인됨 [GIF확인]: 발사가 정확히 2틱마다 반복.
 4) 슬래시(검기) 이펙트는 팩에 없지만 GIF 에는 있고, 재생 길이를 읽어 왔습니다 -> 5번 섹션에 제작 스펙으로 정리.
 5) 피격 시작 프레임이 "흰색 실루엣 1~2프레임" 인 것을 GIF 에서 확인 -> 히트 플래시 규칙 추가.
 6) 착지 먼지는 접지 포즈 "다음 프레임" 에 시작 [GIF확인]. 이 한 프레임 차이로 GIF 와 느낌이 같아집니다.
