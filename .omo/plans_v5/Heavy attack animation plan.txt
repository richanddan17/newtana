1. 좌표계 약속 (이 문서 전체 공통)
------------------------------------------------------------------
  기준점(발 앵커) = 캐릭터 셀 안의 (18, 37) 도트 (셀 좌상단 기준, y 아래로 +)
      x=18 : 다리 두 개의 가운데   /   y=37 : 바닥 접지선(그림자 점 바로 위)
  이 문서의 모든 좌표는 "발 앵커 = (0,0)", 오른쪽 +x, 아래 +y (화면 좌표) 입니다.
  엔진이 y-up(위가 +)이면 y 부호만 뒤집으면 됨. (아래 표에 y-up 값도 같이 적음)
  피벗 정규화값: x = 18/40 = 0.450,  y(위에서) = 37/38 = 0.974  (아래에서 0.026)
  좌우 반전: 발 앵커 기준으로 모든 x 부호만 반대로 (-x). 히트박스/VFX 오프셋 모두 동일.

4. 게임 월드 이동량 (제안 - 측정값 아님, 연출에 맞게 조절)
------------------------------------------------------------------
  스프라이트가 제자리 재생이라, 실제로 앞으로 나가는 거리는 엔진에서 따로 줘야 함.
  근거: F1 스트릭이 몸 뒤쪽(-30~-10)에 나옴 = 앞으로 돌진하는 연출,
        호가 몸 앞 79도트까지 닿음, 몸 폭은 15도트.

  프레임   제안 지속   월드 x 이동(앞으로)   월드 y 이동
  ------   ---------   -------------------   -----------
  21       50 ms       +6 도트               0
  22       70 ms       +8 도트               0   (점프는 스프라이트에 이미 포함)
  23       70 ms       +6 도트               0
  24       70 ms       0                     0
  25       80 ms       0                     0
  26       100 ms      0                     0
  합계 약 +20 도트 (몸 폭의 1.3배). 더 길게 하려면 22번 이동만 늘리면 됨.
  ※ y는 따로 올리지 말 것: 점프 높이가 스프라이트에 그려져 있어서 이중 적용됨.
  ※ 충돌체(바닥 판정)는 땅에 두고, 공중 구간(22~25)은 피격 박스만 위로 올라간 것으로 처리.

6. VFX 위치 (캐릭터에 붙이는 오프셋)
------------------------------------------------------------------
  측정 결과: 모든 VFX 프레임(F1~F5, S1)이 캐릭터 셀 기준으로 같은 위치에 고정되어 있음.
  VFX 셀(115x70)의 좌상단 = 캐릭터 셀 좌상단에서 (-12, -28) 도트.
  => 발 앵커 기준으로는 VFX 셀 좌상단이 (-30, -65), 셀 중심이 (+27.5, -30) (y-up이면 +30).

  엔진 설정 예 (VFX 스프라이트 피벗을 셀 중심으로 둘 때):
      VFX 위치 = 캐릭터 발 앵커 + (+27.5, -30)   [y-down]  /  (+27.5, +30)  [y-up]
      프레임마다 위치를 바꿀 필요 없음 (모두 같은 오프셋). 캐릭터 자식으로 붙이면 됨.
      좌우 반전 시: 오프셋 x -> -27.5 + 스프라이트 flipX

  각 VFX 프레임의 실제 그림 범위 (발 앵커 기준, y-down):
      F1  x -30~-10   y -11~-4     몸 뒤쪽 스트릭 (히트 없음)
      F2  x -15~+79   y -63~+2     최대 크기, 몸 뒤 15도트 ~ 앞 79도트, 높이 65
      F3  x  +7~+85   y -64~+5
      F4  x +33~+85   y -64~+5
      F5  x +37~+79   y -60~+4     잔상 (히트 없음)
      S1  x +62~+77   y -20~-4     바닥 쪽 금색 불꽃 (히트 없음)

9. 윤곽선 제거 메모
------------------------------------------------------------------
  - 어두운 윤곽 픽셀(R,G,B 최대값 150 미만)을 투명 처리. 슬래시 내부 색은 모두 밝은 파스텔이라 겹치지 않음.
  - 호의 좌표/크기는 안 변함: 바깥 한 겹이 사라져서 호가 약 1도트 얇아졌을 뿐, 셀 위치/피벗은 동일.
  - 어두운 배경에서는 그대로 쓰고, 밝은 배경에서는 흰 끝부분이 약해 보일 수 있어서 Normal 블렌드 +
    살짝 어두운 글로우를 깔거나, 밝은 맵에서만 윤곽 있는 원본을 쓰는 방법도 가능.
  - 판정 좌표(7장)는 윤곽선 제거본 기준. 원본(윤곽 있음)은 가장자리 1도트씩 더 큼.
