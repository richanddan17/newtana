# Sprite Asset Spec (v5 - player_1)

플레이어 스프라이트 에셋의 규격을 한곳에 정리한다. animation-state-system.md, hitbox-hurtbox-system.md, weapon-projectile-system.md가 이 문서의 값을 참조한다.

에셋 파일은 player_1_one_cycle.zip의 player/ 폴더(motion/, vfx/, trim_report.json)에 있다.
값의 출처: 업로드된 시트를 직접 분석한 값(셀 크기, 프레임 수)과, 이 문서가 정한 기본값(PPU 등)을 구분해서 적는다.

==================================================
[1. 시트 구조 (분석으로 확인한 값)]
==================================================

- 원본은 GIF를 시트로 변환한 것이라 같은 사이클이 여러 번 반복되어 있었다. 한 사이클만 남긴 시트를 쓴다. (파일 이름은 원본과 같음)
- 모든 시트는 가로 5칸 그리드, 왼쪽에서 오른쪽, 위에서 아래 순서가 프레임 순서다.
- 프레임 수가 5 미만이면 칸 수만큼 가로로만 쓴다.
- 시트마다 셀 크기가 다르다. (아래 표)

==================================================
[2. 임포트 설정 (기본값, 확정 아님)]
==================================================

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 미정. 셀이 220x304 이상이므로 도트 16이 아닐 가능성이 크다. 캐릭터 몸 높이(유닛)를 먼저 정하고 PPU를 역산한다. (예: 캐릭터를 2유닛 높이로 둘 때 몸통 픽셀 높이로 계산)
- Filter Mode: 아트 스타일 확인 후 결정 (도트풍이면 Point, 일반 일러스트면 Bilinear) - 미확인
- Compression: None
- 슬라이스: Grid By Cell Size, 아래 셀 크기 사용

==================================================
[5. Pivot]
==================================================

- 시트마다 셀 크기가 다르므로 pivot은 정규화 좌표가 아니라 "발 위치(바닥 중앙)가 같은 월드 점"에 오도록 시트별로 정한다.
- 방법: Idle 셀에서 발 아래 중앙 픽셀 좌표를 재고, 다른 시트에서도 같은 발 위치 픽셀을 pivot으로 쓴다. 셀이 커진 공격 시트는 몸 위치가 셀 안에서 어디인지 먼저 재야 한다. (미측정)
- 측정 전에는 Bottom Center를 임시값으로 쓰고, Idle/Run/Attack을 겹쳐 놓고 어긋나는 시트만 고친다.

[7. 충돌 판정과의 관계]
==================================================

- 이동 Collider와 Hurtbox는 Idle 몸통 기준으로 고정한다. 시트 셀 크기(공격 시트가 넓음)를 따라가지 않는다.
- 공격 판정(히트박스)은 공격 시트의 프레임 번호 구간으로 정하고 hitbox-hurtbox-system.md에서 관리한다.
- vfx에는 기본적으로 판정이 없다. 캐스트 판정은 발사체/범위 오브젝트가 따로 갖는다. (weapon-projectile-system)
